KEYJAM

v0 · Pilot

Your keyboard is now an instrument. Type anywhere and music plays. Stop, and it stops.

Download for Mac

macOS 11+ · Apple Silicon (M1 or later) · 97 MB

Install
  1. Open the DMG, drag KeyJam to Applications.
  2. Open it. If macOS blocks it, go to System Settings → Privacy & Security and click Open Anyway.
  3. Turn on KeyJam in Privacy & Security → Accessibility.
  4. Click the KeyJam icon in the menu bar and start typing.
Modes
MUSICThe song plays while you type.
FXA sound effect for every key.

KeyJam only reads which key was pressed. Nothing is recorded or sent anywhere.

Still blocked? Run this in Terminal:xattr -dr com.apple.quarantine /Applications/KeyJam.app
